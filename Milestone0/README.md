# Milestone 0 — Foundations of Low-Level C

> ⚠️ **Note for 42/Codam Students:** This code is for reference and portfolio purposes only. Do not copy-paste; write and understand your own implementation.

## Overview

**Milestone 0** marks the beginning of the Codam Core Curriculum. The objective of this milestone is to build a rock-solid foundation in **C99**, manual memory management, pointer arithmetic, and Makefile build automation without relying on standard library shortcuts.

## Projects in this Milestone

| Project | Language | Core Concepts |
| :--- | :--- | :--- |
| **[Libft](./Libft)** | `C` | Memory allocation (`malloc`/`free`), raw byte manipulation, string parsing, and singly linked lists (`t_list`). |

### [Libft](./Libft)
A custom static C library (`libft.a`) recreating standard `libc` functions from scratch, alongside additional utility functions and linked list manipulation routines. This library serves as the foundational building block integrated into subsequent C projects across the curriculum.
